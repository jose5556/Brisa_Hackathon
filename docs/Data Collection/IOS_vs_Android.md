| Dados                                                  | Android                                                       | iOS                                                            | Diferença                                       |
| ------------------------------------------------------ | ------------------------------------------------------------- | -------------------------------------------------------------- | ----------------------------------------------- |
| **GPS (Latitude/Longitude)**                           | `com.google.android.gms.location.FusedLocationProviderClient` | `CoreLocation` (`CLLocationManager`)                           | Muito semelhante.                               |
| **Precisão GPS** (`gpsAccuracyMean`, `gpsAccuracyMax`) | `Location.getAccuracy()`                                      | `CLLocation.horizontalAccuracy`                                | Equivalente direto.                             |
| **Altitude** (`altitudeDelta`)                         | `Location.getAltitude()`                                      | `CLLocation.altitude`                                          | Equivalente direto.                             |
| **Precisão Vertical**                                  | Não usada atualmente                                          | `CLLocation.verticalAccuracy`                                  | iOS fornece uma métrica extra útil.             |
| **Perda de sinal GPS** (`gpsLostRatio`)                | `LocationAvailability.isLocationAvailable()`                  | Erros do `CLLocationManagerDelegate` + timeout de atualizações | Implementação diferente, resultado equivalente. |
| **Barômetro** (`pressureDelta`, `pressureSlope`)       | `SensorManager` + `Sensor.TYPE_PRESSURE`                      | `CoreMotion` + `CMAltimeter`                                   | Equivalente direto.                             |
| **Acelerômetro**                                       | `Sensor.TYPE_ACCELEROMETER`                                   | `CMMotionManager`                                              | Equivalente direto.                             |
| **Movimento / Parado** (`stationaryRatio`)             | Cálculo manual via acelerômetro                               | `CMMotionActivityManager` ou acelerômetro                      | iOS possui API mais avançada pronta.            |
| **Bluetooth BLE Scan** (`bleCountMean`)                | `BluetoothLeScanner`                                          | `CoreBluetooth` (`CBCentralManager`)                           | Muito semelhante.                               |
| **BLE RSSI** (`bleRssiMean`)                           | `ScanResult.rssi`                                             | `didDiscover(... RSSI:)`                                       | Equivalente direto.                             |
| **Wi-Fi AP Count** (`wifiCountMean`)                   | `WifiManager.scanResults.size`                                | ❌ Não disponível                                               | Grande limitação do iOS.                        |
| **Wi-Fi RSSI Médio** (`wifiRssiMean`)                  | `ScanResult.level`                                            | ❌ Não disponível                                               | Apple bloqueia acesso.                          |
| **Wi-Fi Delta** (`wifiCountDelta`)                     | Comparação entre scans                                        | ❌ Não disponível                                               | Não pode ser implementado.                      |
| **Magnetômetro (Campo Magnético)**                    | `SensorManager` + `Sensor.TYPE_MAGNETIC_FIELD` | `CoreMotion` (`CMMotionManager.magnetometerData`) | Equivalente direto. |
| **Intensidade Magnética Média** (`magneticFieldMean`) | `SensorEvent.values[0..2]`                     | `CMMagnetometerData.magneticField`                | Equivalente direto. |
